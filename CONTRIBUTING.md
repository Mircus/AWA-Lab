# Contributing

Contributions are welcome for review once the project is hosted. Please open an issue explaining the mathematical point, preferably with a small reproducible counterexample and a source. Keep dependency additions minimal.

Before proposing a change run `pytest -q` and `python scripts/run_notebooks.py`. A notebook should state assumptions, distinguish theorem from numerical evidence, and identify conventions (e.g. min-plus, base field, monomial order).

This repository has no general-purpose open-source license yet; obtain permission before redistributing modified copies.
